## 📖 Tentang Communify

**Communify** adalah aplikasi asisten perjalanan yang dirancang khusus untuk para pejuang transportasi publik di kawasan **Jabodetabek**. Pernahkah Anda ketiduran di KRL, asyik mendengarkan musik di bus Transjakarta hingga terlewat halte transit, atau bingung mencari peron perpindahan kereta di Stasiun Manggarai?

Communify hadir sebagai solusi navigasi *hands-free*:
- 🎧 **Dengarkan Musik Tanpa Khawatir**: Pengumuman suara otomatis (Text-to-Speech) berbahasa Indonesia akan masuk langsung ke earphone/TWS Anda sebelum stasiun transit atau tujuan akhir tiba.
- 📍 **Pelacakan GPS Latar Belakang (*Foreground Service*)**: Tetap melacak posisi Anda secara presisi meskipun layar HP dimatikan atau HP dimasukkan ke dalam saku.
- 🚊 **Moda Transportasi Lengkap**: Mendukung **KRL Commuter Line**, **Transjakarta BRT (14 Koridor Utama)**, **MRT Jakarta**, serta **LRT Jabodebek & LRT Jakarta**.

## ✨ Fitur Unggulan

| Fitur | Deskripsi |
| :--- | :--- |
| 🎧 **Audio Announcement (TTS)** | Suara asisten otomatis mengabarkan *"Stasiun berikutnya...", "Bersiap untuk transit di...",* dan *"Tiba di stasiun tujuan"*. |
| 🔔 **Heads-Up & Haptic Alert** | Notifikasi prioritas tinggi dengan getaran haptik saat mendekati target geofence stasiun (radius 500m & 150m gate). |
| 🗺️ **Multi-Hop Transit Routing** | Pencarian rute tercepat (*Dijkstra*) lengkap dengan panduan nomor peron & jalur transit (Update: Pola SO-7 Manggarai & Gedung Baru Tanah Abang). |
| 🔋 **Hemat Baterai & Offline Ready** | Database stasiun/halte tersimpan lokal dalam aplikasi, hemat kuota dan baterai. |
| 🌿 **Eco-Tracker (CO₂ Saved)** | Menghitung estimasi kontribusi pengurangan emisi karbon dari perjalanan harian Anda. |
| 🧪 **Mode Simulasi Virtual** | Ingin coba dulu sebelum naik kereta? Coba rute virtual dengan kecepatan simulasi 1x–5x. |

## 📲 Panduan Instalasi APK di Android

Karena aplikasi ini didistribusikan secara independen (belum di Google Play Store), ikuti langkah mudah berikut untuk memasangnya di HP Android Anda:

1. **Unduh File APK**:
   - Klik tombol [**Download APK Versi Terbaru**](https://github.com/zyfdwm/communify-app/releases/latest) atau pilih file `.apk` di bagian tab **Assets** di halaman Releases.
2. **Buka File yang Diunduh**:
   - Buka notifikasi download atau cari file `Communify-v1.0.0.apk` di folder *Downloads* file manager Anda.
3. **Izinkan Instalasi dari Sumber Tidak Dikenal (*Install Unknown Apps*)**:
   - Jika muncul peringatan keamanan sistem Android:
     - Pilih **Settings / Pengaturan**.
     - Aktifkan opsi **"Allow from this source / Izinkan dari sumber ini"** untuk browser (Chrome/Brave) atau File Manager yang Anda gunakan.
4. **Pasang & Buka Aplikasi**:
   - Tekan tombol **Install / Pasang**.
   - Buka aplikasi Communify, lalu berikan **Izin Akses Lokasi (Location Permission)** agar fitur pelacakan GPS otomatis dapat berjalan dengan optimal.
